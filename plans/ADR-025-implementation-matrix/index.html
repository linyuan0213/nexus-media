    结论¶

    主链路（Provider → 合成 → 身份 → 订阅 → 刮削/NFO → 探索页）已经可用。 尚未完成的主要是：人员实体、ProviderContext/限流熔断、跨源链接审核、历史表 identity 列、NamingProfile 实际渲染、多源搜索/统一 lookup API、可观测性，以及真实库迁移与提交。
